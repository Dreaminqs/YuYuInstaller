# YuYuInstaller Companion — Tarayıcı Uzantısı (Chrome / Edge / Brave / Opera / Firefox)

Bu klasör **YuYuInstaller v1.2.7 Pro** masaüstü uygulamasının resmi tarayıcı uzantısını ve mağaza yükleme paketlerini içerir.

## Özellikler
1. **Sayfa İçi Hızlı İndirme Butonu:** Desteklenen medya ve anime sitelerinde (SonAnime, OpenAnime, Animecix, Diziwatch, YouTube, Twitch, Kick, TikTok, Instagram, X/Twitter) sağ altta **"YuYu ile İndir"** butonu çıkar.
2. **Sağ Tık Menüsü:** Herhangi bir sayfaya veya linke sağ tıklayıp **"YuYuInstaller ile Analiz Et"** veya **"Hemen İndir"** seçebilirsiniz.
3. **Toolbar Popup Penceresi:** Tarayıcı sağ üst köşesindeki YuYu ikonuna tıklayarak masaüstü bağlantı durumunu görebilir, kalite/bölüm seçimi veya tek tıkla indirme başlatabilirsiniz.
4. **Otomatik Başlatma (`yuyu://` + `127.0.0.1:48652`):** YuYuInstaller açıksa yerel port üzerinden 1 milisaniyede pencereyi öne getirir; kapalıysa `yuyu://` protokolü üzerinden uygulamayı otomatik çalıştırır.

---

## Kendi Tarayıcınıza Hemen Yükleme (Geliştirici Modu)

### Chrome / Brave / Edge / Opera:
1. Tarayıcı adres çubuğuna `chrome://extensions` (veya `edge://extensions`) yazın.
2. Sağ üstten **Geliştirici modu (Developer mode)** anahtarını açın.
3. **Paketlenmemiş öğe yükle (Load unpacked)** butonuna tıklayıp bu `browser_extension` klasörünü seçin.

### Firefox:
1. Adres çubuğuna `about:debugging#/runtime/this-firefox` yazın.
2. **Geçici Eklenti Yükle (Load Temporary Add-on...)** butonuna tıklayıp `browser_extension/YuYuInstaller_Extension_Firefox.zip` dosyasını seçin.

---

## Resmi Uzantı Mağazalarına Yükleme Hazır Paketleri
Hazır `.zip` dosyaları doğrudan mağaza geliştirici panellerine yüklenebilir:
- **Firefox Add-ons (`addons.mozilla.org` — Ücretsiz):** `YuYuInstaller_Extension_Firefox.zip`
- **Microsoft Edge Add-ons (`partner.microsoft.com` — Ücretsiz) & Chrome Web Store:** `YuYuInstaller_Extension_Chrome_Edge.zip`
